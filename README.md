# 📱 Ushan Mobile – Business Website

A modern, responsive business website developed for **Ushan Mobile**, a mobile repair and service shop.
The website is designed to improve online presence, showcase services, and allow customers to easily understand and connect with the business.

---

## 🌐 Live Demo

* Website: (https://ushanmobile.netlify.app/)

---

## 🎯 Project Purpose

The main goal of this project is to:

* Establish an online presence for Ushan Mobile
* Showcase mobile repair and related services
* Improve customer engagement
* Provide a clean and professional digital identity
* Make the business accessible on all devices

---

## ✨ Key Features

* 📱 Fully responsive design (mobile, tablet, desktop)
* 🏠 Attractive landing page with business introduction
* 🔧 Services section (mobile repair, software fixes, etc.)
* 📞 Contact / inquiry section for customers
* ⭐ Testimonials section for customer feedback
* ⚡ Fast loading and optimized UI
* 🎨 Modern and clean user interface

---
